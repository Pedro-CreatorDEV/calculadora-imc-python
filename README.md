### 🎯 Sobre o Projeto & Referência de Estudo
Este projeto foi desenvolvido a partir de uma das aulas práticas do curso **Python 3 do Básico ao Avançado (com projetos reais)** na **Udemy**, ministrado pelos professores **Luiz Otávio Miranda** e **Tales Calogi**.

O objetivo do exercício é consolidar os fundamentos da linguagem **Python**, incluindo lógica de programação, manipulação de variáveis, operadores aritméticos, formatação de strings e estruturas condicionais, servindo como base para evoluções próprias e validações de dados.

---

### 📊 Tabela de Classificação Utilizada
O cálculo segue a fórmula padrão IMC = peso/ altura **2 e utiliza as faixas de referência:

| Faixa de IMC | Classificação |
| :--- | :--- |
| Abaixo de 18,5 | Abaixo do peso |
| Entre 18,5 e 24,9 | Peso normal |
| Entre 25,0 e 29,9 | Sobrepeso |
| 30,0 ou acima | Obesidade |

---

 ✨ Funcionalidades
- Cálculo automatizado do Índice de Massa Corporal (IMC).
- Formatação numérica para leitura clara no terminal.
- Estrutura modular preparada para adição de classificação detalhada, faixa de peso ideal e validação de entradas.
